# Zomato Dataset – Basic Data Operations

## 📌 Project Overview

This project is based on the Zomato restaurant dataset obtained from Kaggle.

The project focuses on performing basic data manipulation and preprocessing operations using Python and Pandas.

## 📂 Dataset

**Dataset:** `zomato.csv`

The dataset contains information about Zomato restaurants, including restaurant names, locations, ratings, votes, cuisines, online ordering, approximate cost, and other related attributes.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
- CSV Dataset

## 🔍 Operations Performed

The following basic operations were performed on the dataset:

- Loaded the `zomato.csv` dataset
- Explored the dataset
- Sorted the data
- Identified duplicate values
- Removed duplicate values
- Found unique values
- Examined different columns and their values
- Displayed the processed dataset

## 🎯 Objective

The objective of this project was to understand and practice basic data manipulation techniques using Python and Pandas on a real-world dataset.

## 📁 Files

- `zomato.csv` – Dataset used for the project
- `zomato.ipynb` – Jupyter Notebook containing the Python code and operations performed on the dataset
